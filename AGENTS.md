# WaterMind — Instrucciones generales

- Repositorio oficial: https://github.com/anndreesh/WaterMind
- Producción: https://water-mind-kappa.vercel.app
- Realizar los cambios del proyecto en GitHub; no modificar copias locales del código en el PC.
- Crear un commit enfocado y detallado por cada cambio solicitado.
- Publicar a producción y verificar el despliegue y el comportamiento cuando sea factible.
- Si faltan credenciales, permisos o aprobación externa para publicar, completar el cambio y commit e informar el bloqueo concreto.
- Para probar GuaTec, seleccionar `Invitado` e ingresar un nombre de usuario aleatorio.
- No agregar ni publicar archivos de memoria privada en este repositorio.
